# skills/engineering

Daily code-work skills.

| Skill | Description |
|---|---|
| [commit](./commit/SKILL.md) | Conventional Commits via heredoc. Groups changes logically, applies type+scope, never amends. |
| [merge](./merge/SKILL.md) | Wait for checks, merge PR, clean up branch, optionally promote to prod. Pairs with `/commit`. |
| [promote-settings](./promote-settings/SKILL.md) | Compare `.claude/settings.local.json` vs `settings.json`; promote stable permissions to repo scope. |
| [sync-plugin-manifest](./sync-plugin-manifest/SKILL.md) | Export installed Claude Code plugins to a churn-free manifest for git tracking. |
